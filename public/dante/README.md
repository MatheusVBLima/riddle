As adaptações locais são apenas a cópia para distribuição junto do jogo; a
licença CC BY-SA 2.5 continua valendo.

## Referências musicais externas

As fases de música apontam para as gravações de *Dante Symphony*, de Franz
Liszt, disponibilizadas na página de referência do IMSLP. O jogo não baixa nem
redistribui essas gravações; o player externo mantém a atribuição à fonte:
<https://imslp.org/wiki/Dante_Symphony_(Liszt,_Franz)>.
